# HarmonyOS client

Native ArkTS / ArkUI client for HarmonyOS 7.0 (API 26) and newer, with an ArkWeb WebRTC data channel.

Open this directory in DevEco Studio with the API 26 SDK. From the repository root, run `pnpm exec vitest run apps/harmony/tests` for Node conformance tests; native compilation and device validation require the HarmonyOS SDK.

See the [client guide](../../docs/harmony-client.md) for build commands, signing, CI, security boundaries and maintenance.
