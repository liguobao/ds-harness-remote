# 对齐 dsh-Go（A 组功能）落地记录

> 对象：`ccch1mneyyy/dsh-Go`（Android 客户端，Flutter+Kotlin）。
> 本仓库只做**客户端侧可落地**的部分（A 组），需要主机/协议支持的部分（B 组）与平台不适用的部分（C 组）明确不做。

## 已落地（0.17.81–0.17.84）

| 编号 | 能力 | 实现要点 | 依赖 |
|---|---|---|---|
| A1 | 连接详情 + 测延迟 | 顶栏传输徽标可点开面板：传输、握手分段耗时、链路静默、回落原因、精简历史状态；「测延迟」连发 3 个 `harness.transport.describe` 取平均；WebRTC 桥用 `getStats()` 取选中候选对（最多重试 6 次 × 600ms），拿不到时显示「浏览器未给出选中候选对」 | 纯客户端 |
| A2 | 精简历史 | 设置开关 → 连上后 `remote.history.configure { compact }`；持久化在 SecureStore，下次开会话生效 | 主机 0.6.4 已支持（实测通过） |
| A3 | 敏感内容打码 | `sk-*` / `ghp_*` / `github_pat_*` / `Bearer <token>` / ≥32 位 hex 默认打码；气泡提示「已遮挡敏感内容 · 点此看原文」；设置可整体关 | 纯客户端 |
| A4 | 轮次导航 + 每轮用量 | 底部胶囊 `↑ 3/9 · 12 步 · 1m20s ↓`；`turn/start` 起计时、`tool/*` 累步数、`turn/end` 汇总（若带 `usage`/`tokens` 一并显示）；滚动时位置同步 | 纯客户端 |
| A5 | 主题色 | 深海 / 森林 / 暖沙 / 玫紫 + 默认，只换背景/面板/表面，强调色保持品牌蓝青；设置里选择器即时生效并落盘 | 纯客户端 |
| A6 | 桌宠（鲸娘） | 右下角挂件四态：🐳 干活 / 🙋 等确认 / ✨ 刚做完 / 🌙 待命；状态由 `generating`、待审批/待回答、`turn/end` 时刻推导，无额外定时器；设置可关 | 纯客户端 |

## 明确不做

- **A8 对话回放链接**：dsh-Go 的方案是「加密链接 + 回放服务端」。本仓库的 relay server 可以扩 `/share`，但需要重启线上服务；用户决定跳过。
- **B 组**（待办条、`@` 引用、技能组、排队消息管理、后台任务/子代理/轨迹/交付物/终端）：需要 `ds-harness-remote` 主机侧透传 endpoint。
- **C 组**（本机 Linux 引擎、安全模式、SSH 主机、App 内网页版）：平台或架构不适用。

## 已知差异

- 分享是**文本卡片**，不是图片卡片（生成图片需要 `componentSnapshot` 截图组件，成本更高）。
- ICE 候选对显示是 best-effort：ArkWeb 的 `getStats()` 未给出 nominated 对时降级显示传输类型。
