# DSH Remote 界面设计系统

更新时间：2026-10-08；以下描述当前源码与交互规则，不代表真机可访问性验收。

## 1. 设计来源

Android token 以 [theme.ts](../../apps/android/src/ui/theme.ts)为准，主题切换由
[theme-context.tsx](../../apps/android/src/ui/theme-context.tsx)管理，导航以 [App.tsx](../../apps/android/App.tsx)为准。
Desktop 复用 Harness 官方 Workspace / Session / Conversation UI；Remote 只增加账号、Host/工作区选择、设置和 Header。
CodeX / ACP 在内存中投影到同一原生 UI，不增加独立会话页面或持久化展示数据库。

## 2. 主题与颜色

Android 支持跟随系统、浅色与深色主题；当前 token 是源码中的 sRGB/RGBA 值，不使用早期 OKLCH moss 方案。

| 角色 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| background | `#F5F5F7` | `#0F1114` | 页面背景 |
| surface | `#FFFFFF` | `#1A1D23` | 分组与浮层 |
| surfaceStrong | `#F0F2F5` | `#252932` | 次级表面 |
| ink | `#1D1D1F` | `#F2F3F5` | 主要文字 |
| muted | `#5F636B` | `#9AA0A6` | 次级文字 |
| primary / accent | `#1677FF` | `#4096FF` | 主要操作与选中态 |
| success | `#276A3C` | `#49AA6E` | 成功状态 |
| warning | `#825306` | `#D89614` | 需注意状态 |
| danger | `#A73A32` | `#E86E6B` | 错误与危险操作 |
| border | `#D9E2EC` | `#3A4048` | 边界 |

完整 pressed/soft/disabled/separator/scrim 等值引用源码，不在各组件复制新色表。
状态同时提供文字或图标，不单靠颜色区分在线、重连、权限或选中项。

## 3. 字体与尺寸

Android 使用系统字体，代码与文本预览使用等宽字体；字体随系统缩放。

| token | 字号 / 行高 | 字重 |
| --- | --- | --- |
| hero | 32 / 38 | 700 |
| title | 24 / 30 | 700 |
| heading | 18 / 24 | 600 |
| body | 16 / 24 | 400 |
| bodyStrong | 16 / 22 | 600 |
| small | 14 / 20 | 400 |
| smallStrong | 14 / 20 | 600 |
| caption | 12 / 16 | 500 |

spacing：4、8、12、16、20、24、32、40 dp；radius：8、12、16 dp 和 pill。
页面和控件使用共享 token；操作区域保持足够触达空间，图标按钮提供可访问名称。
具体点击区域、长标题、大字体和窄屏效果应以组件及实际设备检查为准。

屏幕旋转：Android 不锁定方向，跟随系统旋转设置；同一导航/连接状态在横竖屏复用。
聊天消息与输入栏在宽窗口中使用居中的可读列（最大 760 dp）；底部弹层与工作区对话框的最大高度
按当前窗口计算（窗口高度低于 520 dp 时约占 92%），内容超出时在层内滚动；横屏或短窗口中压缩
输入栏与隐私提示，并在旋转后重新同步 IME inset，避免用旧方向的键盘坐标计算底部留白。
这些规则由 `apps/android/src/ui/responsive.ts` 与各面板共同实现，不代表已完成大字体、TalkBack
或分屏窗口的真机验收。

## 4. Android 导航

主机会话侧边栏顶部仅显示居中的主机名，左侧返回箭头直接回到主机列表，右侧保留刷新；点击遮罩或系统返回键仅收起侧边栏。首组固定为“当前工作”，汇总本次远程已使用且未归档的对话，默认展开，无对话时显示空态；运行中的对话在汇总及工作区分组内均显示转动图标与“运行中”文字，状态变化后实时更新；下方工作区保持目录顺序。侧边栏采用统一的紧凑导航列表：工作区与对话同为 14dp 字号、至少 48dp 点击区域；工作区名称稍加粗，后端和数量使用弱化小字，展开箭头固定在末尾。图标不加底板，工作区行不铺底色；对话相对工作区缩进 20dp，不绘制树状连线或行分割线。展开分组顶部留 8dp，折叠分组不增加额外外边距；完整目录在对话信息面板查看。选中对话使用主题中性 surfaceStrong 底色、正常正文色与略加粗标题，保留低强调的勾选标记；“显示更多”与空态对齐对话标题。“当前工作”保持同一行样式，不作为独立大卡片。

侧栏展开/折叠状态按主机和分组保存在手机，重新打开或重启应用后恢复；恢复完成前显示加载状态，避免先展开再收起。该偏好独立于主机工作区页。

完成 bootstrap 后，已有配置的用户进入设备列表；未配置时进入 Server 设置/账号授权，完成后进入设备列表。
不在启动时自动选择或连接 Host。
登录页提供「扫码登录」点击入口：初始不请求 provider、不生成二维码，点击入口后才加载并在页内展示二维码，
手机扫码授权后自动注册本设备；手机、平板和大屏都保留知乎/GitHub 浏览器 OAuth 与邮箱密码登录，大屏使用
更大的二维码。二维码只编码 Server 返回的同源 `scanUrl`，不包含账号 token；修改服务地址会作废旧二维码，
离开扫码页停止轮询。

平板聊天采用双栏：宽度 ≥760 dp 时左侧常驻按当前工作/工作区/其他对话分组的会话列表，右侧显示
会话头部、消息与输入栏；在左栏切换会话只更新右侧内容，返回按钮回到工作区。窄屏与短窗口仍为
手机单栏，会话列表继续以 Modal 抽屉打开。

连接进度页在主机名下以居中的单行 `DSH 版本号 | Plugin 版本号` 展示设备目录报告的版本，缺失时明确显示版本不可用。
工作区页标题只显示带下划线、整段可点击的主机名，点击进入主机信息；右上角只保留新建工作区入口。
网络路径与详细诊断在已连接主机的信息页直接展开，并复用于对话信息面板。
首页及单操作标题栏两侧保留对称空间，标题按屏幕居中；返回、更多和新建图标不加外层按钮背景、边框或阴影。
主机信息页在主机名后提供编辑图标用于重命名，右侧展示系统类型，同一行不重复展示网络类型；设备信息分别列出 DSH 和 Remote 插件版本。
主机列表以纯文字显示在线/离线状态，不使用圆点或胶囊底色；重命名入口仅保留在主机信息页。
信息行的标签按文字宽度占位、最多占行宽的 40%，右侧内容使用剩余空间，避免短标签造成不必要的换行。

主路径：设备列表 → 信任/连接 → 工作区内的会话列表 → Chat。
设备详情、连接详情、设置和关于页面属于辅助路径，不使用早期匿名 Pair device 配对流程。
收藏/最近工作区快捷入口先连接所属 Host，再打开该工作区最近会话；没有会话时定位工作区。
工作区作为连接后的首页，返回设备列表；Chat 返回对应工作区/会话路径。
返回设备列表保留当前连接。Android 不提供独立「对话」菜单或跨工作区平铺的会话列表页；会话统一从所属设备的工作区进入。

语言支持跟随系统、英文、简体中文；主题支持跟随系统、浅色、深色。
重连保留支持恢复的工作区/会话选择，换 Host 时丢弃其他 Host 的内存领域状态。

## 5. 会话与输入

会话标题保持单行，点击打开对话信息面板：完整标题、所属工作区、主机、工作区类型、完整目录与对话数，以及当前连接方式、加密与网络详情。点击工作区回到当前主机工作区页并定位该工作区；未分组时回到主机工作区列表。断线时不展示旧网络数据为当前连接。当前标题栏提供轨迹切换、新会话，离线时增加重连动作；标题栏不直接列出 Files/Terminal。
正文使用会话列表或轨迹视图，历史分页与实时帧保持顺序；模型和思考程度仅显示后端报告的选项。

输入栏 `+` 提供附件与工具访问入口；「快捷提示词」在 `+` 旁单独展示，打开后可选择发送、管理和编辑。
Files / Terminal 从「工具访问」选择；轨迹同时有标题栏入口。`/` 命令和 `@` 上下文菜单沿用 Host 支持的语义。
文字/图片发送根据当前后端与 capability 限制；Cursor 仅文字，AGY 图片必须遵守其大小、数量和缓存提示。
未知模型显示沿用 Host 设置；AGY 选择模型/effort 待 Host 确认，历史回复不因后续切换而改标。

会话离线显示文字状态和恢复动作，禁止向无输入权终端或无效会话继续提交操作。
Agent 单次审批、会话权限策略选择、终端输入权是不同交互，不能混为一个开关。

## 6. Files 与 Terminal

当前工具按 Harness / CodeX / ACP 的会话 scope 和 capability 接入；CodeX 工具不再属于禁止项。
不支持某 endpoint 的 Host/后端显示明确错误，不将工具操作转到另一后端。

Files：目录优先、显示当前路径，刷新与层级返回位于面板 Header；文本等宽、可选择、分页只读。
图片适应容器，PDF/Office 使用本地 PDF.js 预览；取消、超限、转换超时和文件版本变化均应有可恢复状态。
PDF 不开放脚本、外链、导出或明文缓存；文本选择和 TalkBack 体验仍待验收。

Terminal：使用本地打包的 xterm WebView，打开面板只列出现有终端；标题栏「＋」才创建新终端。
区分连接、已退出、缺少输入权和 Host 已关闭功能；输入/调整尺寸受连接输入权约束，关闭有确认。
断线不重放输入。终端保持独立深色画布、可访问名称、screen-reader 模式与键盘/特殊按键入口。

工具面板使用共享安全区、键盘 inset 和模态层；IME、硬件键盘、长输出、TalkBack、大字体和真实文件预览另行真机验证。

## 7. Desktop Remote 入口与设置

侧栏底部插件入口保持纵向排列，Remote 位于 DS Bot 等已有插件入口下方、「更多」上方。展开侧栏时 Remote 使用 36px 高的整行图标与文字按钮，长 Host 名称省略；折叠侧栏时使用 36px 图标按钮。悬停显示 Remote 或当前 Host 名称与退出提示，已连接时点击返回本地工作区，两种宽度均保留键盘焦点。DS Bot 团队模式保留账户头像与「连接插件」的原有同一行布局，Remote 独立占据其下方一行，不把 Bot 的内部操作拆成多行。

Remote 模态框展示账号授权、Host、后端分组、实际就绪状态和已有工作区；添加目录入口按领域 authority 限制。
Header 显示远端 Host、传输路径、加密说明、退出和「预览服务」。本机 preview URL 不作为 Android / Remote Web 地址。

详细 Remote 设置中，终端开关切换即保存；端口输入右侧「保存访问设置」只提交 loopback 白名单。
Agent 后端统一列表展示 CodeX / Cursor / AGY，命令可发现不等于已登录或就绪；检测失败关闭后端，检测恢复后由用户开启。
配置保存热更新对应后端，不需要重启整个 DSH。访问设置仅 Host 本地可编辑。

## 8. 状态、文案与验证

状态变化显示文字和具体恢复动作；错误不以 undefined 或内部异常作为主要文案。
图标按钮提供名称、selected/disabled/expanded 状态与必要的辅助提示；无障碍结果以实际检查为准。
动画遵循现有 Modal/组件实现，不宣称全局已有固定 150–220ms 动效或完整 reduced-motion 验收。

界面文案、布局和样式不单独增加自动化测试。类型检查、必要人工烟测和真实设备验证承担展示质量检查；
终端输入权、事件顺序、权限与恢复等核心边界由契约测试保护。未完成验收见[TODO](../TODO.md)。
