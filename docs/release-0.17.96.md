# DSH 远程 · 鸿蒙客户端 0.17.96-lan（1000218）

> 本版是「稳定性 + 多语言 + 自测工具」的一次收口，承接 0.17.86 的局域网直连里程碑。

## 本版做了什么

### 恢复链路（实测停自建 relay 12 秒）

| 版本 | 改动 | 恢复耗时 |
|---|---|---|
| 0.17.87 | `4009 server shutdown` 由「不重连」改为自动退避重连 | 34.8s |
| 0.17.88 | 主机未上线时退避封顶 5 秒 | 27.1s |
| 0.17.92 | 等主机上线期间**不消耗重连次数**（窗口 90 秒）+ 2 秒重试 | 客户端 2 次尝试即恢复 |
| 0.17.96 | 剩余耗时定位在主机插件自身重注册退避（非客户端可压） | — |

### 多语言

- UI 里 313 个文案全部有英文（条目 353），此前只有 106 条
- 新增 `harmony/scripts/check-i18n.mjs`：检查未翻译 / 重复 key / 英文里残留中文 / 空翻译，
  语言名（中文/日本語/English）白名单
- 修掉一处重复 key（`连接` → 设置面板分组改用 `连接状态 / Connection`）

### 连接详情里的「路径」

- ArkWeb 的 `getStats` 传 callback 会被当成非法 selector（实测 TypeError）→ 改无参调用
- 候选对字段不稳定 → 匹配放宽（succeeded / selected / nominated 任一命中）
- 仍拿不到时上报「ICE 状态 + 本机/远端候选数量」

### 工具

- `harmony/scripts/build-local.sh`：本机签名构建（签名材料不入库）
- `harmony/scripts/smoke.sh`：构建 → 装机 → 拉起 → 等连接 → 崩溃检查，一条命令出结论

## 升级

```sh
harmony/scripts/smoke.sh <设备序列号>
```

（调试签名只对签名时在线的设备有效；换正式包前需先卸载。）
