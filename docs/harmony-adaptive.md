# 多端适配口径（鸿蒙客户端）

> 适用版本：`0.17.49-lan`（`1000171`）。目标设备：手机、折叠屏、三折叠、MatePad、2in1/PC（含 MatePad Edge）。
> 依据：DevEco「一次开发多端部署」的断点与栅格建议、API 26 `@ohos.display` / `@ohos.window`，
> 以及本项目在 Edge（QXS-W10，3120×2080）上的实测。

## 1. 断点

一律按**窗口宽度（vp）**取断点，不看设备型号、也不看横竖屏 —— 2in1 窗口可以任意拉伸，
折叠/展开直接体现为窗口尺寸变化。

| 断点 | 宽度 | 典型形态 | 布局 |
| --- | --- | --- | --- |
| xs | < 320 | 小屏手机竖屏 | 单列、满宽 |
| sm | 320 – 600 | 手机竖屏 | 单列 |
| md | 600 – 840 | 手机横屏 / 小折叠展开 / 小平板 | 双栏（高度需 ≥480vp，手机横屏 840×360 除外） |
| lg | 840 – 1440 | 平板、2in1 窗口 | 双栏 |
| xl | ≥ 1440 | 2in1 全屏、三折叠三屏展开 | 三栏 |

断点常量：`services/Adaptive.ets:18-45`（320 / 600 / 840 + 自加 1440）。

## 2. 分栏

- **双栏**：`窗口宽 ≥600vp 且高 ≥480vp`（`showTwoPane()`）。左侧会话栏 + 聊天区。
- **三栏**：`宽 ≥1180vp 且高 ≥560vp`（`showThreePane()`）。再加右侧 300vp「会话详情」常驻栏。
- 阈值取 1180 的理由：再窄下去中间聊天区会被压到 600vp 以下，助手气泡的 88%/780 上限就顶满了。
- 会话栏宽度：默认窗口宽 20%，夹在 260–380vp；用户拖过分隔条后取记住的值，夹在 240–460vp，
  持久化键 `splitWidth`（`SecureStore.loadSplitWidth/saveSplitWidth`）。

## 3. 视觉（分栏衔接）

- 会话栏、详情栏都是**卡片**：圆角 18、1px 细边、四周 8vp 外边距，中间露出窗口底色当缝。
  不再用两条 0.5px 硬边框对撞（那是早期「生硬」的主因）。
- 分隔条默认**完全隐形**，只保留 6vp 命中区；hover 或拖动时才出一条 1–2vp 青色细线。
- 宽屏下消息区 `alignSelf(ItemAlign.Center)` 居中，不再贴着会话栏。
- 分栏时会话行用紧凑密度（上下内边距 7 vs 10、圆角 12 vs 14），同屏多显示两三行。

## 4. 折叠与三折叠

- 监听：`display.on('foldStatusChange')` + `display.on('foldDisplayModeChange')`（`Index.ets` `watchFoldStatus()`）。
- 状态归一：API 26 的双折轴（三折叠）组合值是 `11/12/13`（第一轴展开）、`21/22/23`（第一轴折叠）、
  `31/32/33`（第一轴半折），`foldStateOf()` 按十位数取「第一折轴」状态，归成 展开 / 半折 / 折叠 三态
  （`Adaptive.ets:90-107`）。
- 半折（悬停）布局：消息区与输入坞之间留铰链间隙，输入坞压在下半屏。
  间隙 = 窗口高 × 1.2%，夹在 8–24vp（`hingeGapVp()`）。
  **API 26 的 `window.AvoidAreaType` 只有 SYSTEM / CUTOUT / SYSTEM_GESTURE / KEYBOARD，没有铰链类型**，
  所以只能估；不同机型铰链宽度差异靠这个比例吞掉。

## 5. 安全区与输入

- `expandSafeArea([SYSTEM], [TOP, BOTTOM])` + `getWindowAvoidArea(TYPE_SYSTEM / TYPE_NAVIGATION_INDICATOR)`
  + `avoidAreaChange` 监听，底部不留系统导航条的白边。
- 键盘避让用 `setKeyboardAvoidMode(KeyboardAvoidMode.RESIZE)`（官方推荐的做法，`pan` 会把顶栏顶出屏幕）。

## 6. PC / 2in1 交互口径

| 交互 | 行为 |
| --- | --- |
| 窗口 | 最小尺寸 480×520（`setWindowLimits`），避免被拖成一条缝 |
| 右键 | 会话行、消息气泡、主机卡右键 = 长按菜单（`MouseAction.Press` + `MouseButton.Right`） |
| 键盘 | 顶栏图标、会话行、发送键 `.focusable(true)`，Enter/Space 触发；输入框 **Ctrl+Enter 发送**（普通 Enter 不抢） |
| 悬停 | 会话行 / 主机卡 hover 换底色；分隔条 hover 出线 |
| 拖拽 | 分栏分隔条左右拖动改会话栏宽度，松手落盘 |
| 滚动条 | 双栏/三栏下常显（`BarState.On`），单列仍自动隐藏 |
