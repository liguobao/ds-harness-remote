# DSH 远程 · 鸿蒙客户端 0.17.100-lan（1000222）

> 承接 0.17.86「局域网直连里程碑」，这一版把**断服恢复**、**多语言**、**自测工具**三件事收口。
> 产物：`dshremote-v0.17.100-lan.hap`（调试签名，2.6 MB）；源码在仓库根 `harmony/`。

## 断服恢复：从「必须人切前台」到「自己回来」

| 版本 | 改动 | 实测（停自建 relay 12 秒，客户端全程不碰） |
|---|---|---|
| — | 修前：`4009 server shutdown` 落到「未知关闭码 → 不重连」 | 停在设备列表，**只有 App 回前台才恢复（23s，且需要人）** |
| 0.17.87 | 4009 改为自动退避重连 | 34.8s 自动回到 `已连接 · lan` |
| 0.17.88 | 「主机还没重新注册」时退避封顶 5s | 27.1s |
| 0.17.92 | 等主机期间**不消耗重连次数**（窗口 90s）+ 2s 快重试 | 客户端仅 2 次尝试即恢复 |

剩余耗时主要在主机插件自身的重注册退避（不归客户端管），插件侧 `reconnect.initialDelayMs` 已从 4s 调到 1s。

## 多语言

- UI 文案 **313 → 317 条全部有英文**（此前仅 106 条），条目总数 357
- 新增 `harmony/scripts/check-i18n.mjs`：查未翻译 / 重复 key / 英文残留中文 / 空翻译（语言名白名单）
- 修掉一处重复 key（`连接` → 设置分组改用 `连接状态 / Connection`）

## 连接详情

- ArkWeb 的 `getStats(callback)` 实测直接 TypeError（回调被当非法 selector）→ 改无参调用
- `candidate-pair` 字段不稳定 → 匹配放宽（succeeded / selected / nominated 任一命中）
- 仍拿不到时上报「ICE 状态 + 本机/远端候选数量」，不再只有一句「未给出」

## 文案可操作性

- `4002 invalid access token` → 「登录凭据已失效（4002）：请在设置的「远程」里退出授权后重新登录」
- 等主机回线时不再说「重连失败」，改为「主机还没重新上线，2 秒后再试（已等 X 秒）」

## 工具与工程

| 脚本 | 用途 |
|---|---|
| `harmony/scripts/build-local.sh` | 本机签名构建；签名材料不入库 |
| `harmony/scripts/smoke.sh <设备>` | 构建 → 装机 → 冷启动 → 等「已连接」→ 崩溃检查（含版本号/i18n 前置自检） |
| `harmony/scripts/check-i18n.mjs` | 文案完整性校验 |
| `harmony/scripts/bump-version.mjs [--check]` | 版本号唯一入口（app.json5 与 ServerApi 同步，防止漂移） |

## 实测数据

- **局域网 vs 中继**：`session/list` 3.4s→**1.0s**；`session/follow` 打开 0.85s→**0.08s**
- **熄屏 4 小时后冷启动**：2.9 秒自动连上（`已连接 · lan`）+ 183 个会话快照秒开 + 保活重新持有
- **长稳采样**（每 10 分钟）：服务器始终 200，Edge 连续 50+ 分钟零新增断线，静默探测 0 次

## 升级

```sh
harmony/scripts/smoke.sh <设备序列号>      # 一条命令完成构建/装机/验证
```

> 调试签名只对签名时在线的设备有效；换正式包前需先卸载。
